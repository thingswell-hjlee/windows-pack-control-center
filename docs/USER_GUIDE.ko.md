# 사용자 가이드

## 대시보드 접속

웹 브라우저에서 다음 주소로 접속합니다:

```
http://localhost:8088
```

같은 네트워크의 다른 PC에서 접속하려면 설치된 PC의 IP 주소를 사용합니다:
```
http://192.168.x.x:8088
```

## 메인 대시보드

대시보드 홈에서 다음 정보를 한눈에 확인할 수 있습니다:

- **전체 장비 수**: 등록된 AIBox 장비 총 수
- **온라인 장비**: 현재 정상 연결된 장비 수
- **오늘 이벤트**: 오늘 발생한 이벤트 총 수
- **미확인 이벤트**: 아직 확인되지 않은 이벤트 수

이 통계는 실시간으로 업데이트됩니다.

## 장비 관리

### 장비 목록 보기

왼쪽 메뉴에서 "장비 관리"를 클릭하면 등록된 모든 AIBox 장비 목록을 볼 수 있습니다.

각 장비 카드에 표시되는 정보:
- 장비명
- 장비 ID
- IP 주소
- 상태 (온라인/오프라인/알 수 없음)
- 위치

### 장비 등록

1. "장비 추가" 버튼을 클릭합니다.
2. 다음 정보를 입력합니다:

| 필드 | 필수 | 설명 |
|------|------|------|
| 장비 ID | O | AIBox 장비의 고유 식별자 |
| 장비명 | O | 관리용 이름 (예: "1층 로비 AIBox") |
| 현장 ID | - | 현장/사이트 코드 |
| 현장명 | - | 현장 이름 |
| 위치 | - | 설치 위치 설명 |
| IP 주소 | - | 장비 IP |
| MQTT 호스트 | - | MQTT 브로커 주소 (장비 IP와 동일한 경우가 많음) |
| MQTT 포트 | - | 기본값 1883 |
| MQTT 사용자명 | - | 인증이 필요한 경우 |
| MQTT 비밀번호 | - | 인증이 필요한 경우 |
| 설명 | - | 비고 |

3. "저장" 버튼을 클릭합니다.
4. 장비가 등록되면 자동으로 MQTT 연결이 시작됩니다.

### 장비 수정

1. 장비 목록에서 수정할 장비의 "편집" 버튼을 클릭합니다.
2. 정보를 수정한 후 "저장"을 클릭합니다.

### 장비 삭제

1. 장비 목록에서 삭제할 장비의 "삭제" 버튼을 클릭합니다.
2. 확인 메시지에서 "확인"을 클릭합니다.

> **주의:** 장비를 삭제해도 해당 장비의 이벤트 기록은 유지됩니다.

## 카메라 관리

### 카메라 목록 보기

왼쪽 메뉴에서 "카메라 관리"를 클릭합니다.

### 카메라 등록

1. "카메라 추가" 버튼을 클릭합니다.
2. 다음 정보를 입력합니다:

| 필드 | 필수 | 설명 |
|------|------|------|
| 카메라 ID | O | 고유 식별자 |
| 카메라명 | O | 관리용 이름 (예: "정문 카메라") |
| 연결 장비 | - | 연결된 AIBox 장비 선택 |
| 채널 번호 | O | AIBox에서의 카메라 채널 번호 |
| 위치 | - | 설치 위치 |
| IP 주소 | - | 카메라 IP |
| RTSP URL | - | RTSP 스트리밍 주소 |
| ONVIF 사용 | - | ONVIF 프로토콜 사용 여부 |
| 설명 | - | 비고 |

3. "저장" 버튼을 클릭합니다.

### 카메라 수정/삭제

장비 관리와 동일한 방식으로 편집 및 삭제가 가능합니다.

## 이벤트 관리

### 이벤트 목록 보기

왼쪽 메뉴에서 "이벤트"를 클릭하면 모든 이벤트 목록이 표시됩니다.

### 이벤트 필터링

상단의 필터 옵션을 사용하여 이벤트를 검색할 수 있습니다:

- **장비**: 특정 장비의 이벤트만 표시
- **이벤트 유형**: intrusion, loitering, fire, smoke 등
- **심각도**: LOW, MEDIUM, HIGH, CRITICAL
- **확인 상태**: 전체, 미확인, 확인됨
- **날짜 범위**: 시작일 ~ 종료일

### 이벤트 유형

| 유형 | 설명 |
|------|------|
| intrusion | 침입 감지 |
| loitering | 배회 감지 |
| fire | 화재 감지 |
| smoke | 연기 감지 |
| fall_detection | 넘어짐 감지 |
| line_crossing | 라인 크로싱 |
| object_detection | 객체 감지 |

### 심각도 레벨

| 레벨 | 의미 | 색상 |
|------|------|------|
| CRITICAL | 즉각 대응 필요 | 빨강 |
| HIGH | 긴급 확인 필요 | 주황 |
| MEDIUM | 주의 필요 | 노랑 |
| LOW | 참고 사항 | 파랑 |

### 이벤트 확인 (Acknowledge)

미확인 이벤트를 확인 처리하려면:

1. 이벤트 목록에서 해당 이벤트의 "확인" 버튼을 클릭합니다.
2. 이벤트 상태가 "확인됨"으로 변경됩니다.

### 조치 메모 추가

이벤트에 대한 조치 내용을 기록하려면:

1. 이벤트 목록에서 해당 이벤트의 "메모" 버튼을 클릭합니다.
2. 조치 내용을 입력합니다 (예: "경비원 현장 확인 완료, 오탐으로 판단").
3. "저장"을 클릭합니다.

## 보고서

### 이벤트 보고서 조회

왼쪽 메뉴에서 "보고서"를 클릭합니다.

### 날짜 범위 설정

1. 시작일과 종료일을 선택합니다.
2. 필요시 장비, 이벤트 유형, 심각도 필터를 적용합니다.
3. 조회 결과가 표 형태로 표시됩니다.

### CSV 내보내기

1. 원하는 필터 조건을 설정합니다.
2. "CSV 내보내기" 버튼을 클릭합니다.
3. 필터링된 이벤트 데이터가 CSV 파일로 다운로드됩니다.

CSV 파일에 포함되는 컬럼:
- 이벤트 ID
- 발생 시간
- 장비 ID
- 카메라 ID
- 이벤트 유형
- 심각도
- 신뢰도
- 확인 상태
- 조치 메모

---

## 실시간 알림

대시보드는 SignalR을 통해 실시간으로 업데이트됩니다:

- 새로운 이벤트 발생 시 자동으로 목록에 추가
- 장비 상태 변경 시 즉시 반영
- 대시보드 통계 실시간 갱신

별도의 새로고침 없이 자동으로 최신 정보가 표시됩니다.

---

## 팁 및 참고사항

- 많은 이벤트가 발생하는 환경에서는 필터를 활용하여 중요한 이벤트를 우선 확인하세요.
- CRITICAL 및 HIGH 심각도 이벤트를 우선적으로 확인하는 것을 권장합니다.
- 정기적으로 CSV 내보내기를 통해 이벤트 기록을 백업하세요.
- 장비가 오프라인으로 표시되면 네트워크 연결 상태를 확인하세요.
