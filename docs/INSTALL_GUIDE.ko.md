# Windows Pack Control Center 설치 가이드

## 시스템 요구사항

| 항목 | 최소 사양 |
|------|-----------|
| 운영체제 | Windows 10 (64-bit) 이상 |
| RAM | 4GB 이상 |
| 디스크 | 500MB 이상 여유 공간 |
| 네트워크 | LAN 연결 (MQTT 장치와 동일 네트워크) |
| 포트 | TCP 8088 (대시보드), TCP 1883 (MQTT) |

## 설치 전 확인사항

1. **관리자 권한** - 설치 프로그램 실행 시 관리자 권한이 필요합니다.
2. **포트 가용성** - TCP 포트 8088이 다른 프로그램에서 사용되고 있지 않은지 확인합니다.
3. **방화벽** - 설치 시 자동으로 방화벽 규칙이 추가됩니다.

## 설치 절차

### Step 1: 설치 프로그램 실행

`WindowsPackControlCenter_Setup_1.0.0.exe` 파일을 더블클릭합니다.

### Step 2: 라이선스 동의

라이선스 내용을 확인하고 "동의합니다"를 선택합니다.

### Step 3: 설치 위치 선택

기본 설치 경로: `C:\Program Files\Thingswell\WindowsPackControlCenter`

필요 시 다른 경로를 지정할 수 있습니다.

### Step 4: 설치 옵션 선택

- **바탕화면 바로가기 생성** - 바탕화면에 아이콘을 추가합니다.
- **Windows 시작 시 자동 실행** - 로그인 시 자동으로 서비스를 시작합니다.

### Step 5: 설치 완료

설치가 완료되면 다음 옵션을 선택할 수 있습니다:
- **Control Center 시작** - 바로 서비스를 시작합니다.
- **대시보드 열기** - 브라우저에서 대시보드를 엽니다.

## 최초 실행 설정

### 1. 대시보드 접속 확인

브라우저에서 http://localhost:8088 에 접속하여 대시보드가 정상적으로 표시되는지 확인합니다.

### 2. 장치 등록

1. 대시보드 > 장치 관리 메뉴로 이동
2. "장치 추가" 버튼 클릭
3. 필수 정보 입력:
   - **장치 ID**: AIBox의 고유 식별자
   - **장치 이름**: 관리용 이름
   - **MQTT 호스트**: AIBox의 IP 주소
   - **MQTT 포트**: 기본 1883
4. "저장" 클릭

### 3. 카메라 등록

1. 대시보드 > 카메라 관리 메뉴로 이동
2. "카메라 추가" 버튼 클릭
3. 필수 정보 입력:
   - **카메라 ID**: 카메라 고유 식별자
   - **카메라 이름**: 관리용 이름
   - **연결 장치**: 드롭다운에서 장치 선택
   - **RTSP URL**: 카메라 스트림 주소
4. "저장" 클릭

### 4. MQTT 연결 확인

장치 등록 후 장치 목록에서 상태가 "온라인"으로 변경되는지 확인합니다.
(최대 60초 소요)

## 설치 확인

설치가 정상적으로 완료되었는지 다음 항목을 확인합니다:

| 확인 항목 | 방법 | 기대 결과 |
|-----------|------|-----------|
| 서비스 실행 | 작업 관리자 확인 | `ControlCenter.Gateway.exe` 프로세스 존재 |
| 대시보드 접속 | http://localhost:8088 | 대시보드 페이지 표시 |
| 데이터 디렉토리 | 탐색기 확인 | `C:\ProgramData\Thingswell\WindowsPackControlCenter` 존재 |
| 방화벽 규칙 | `netsh advfirewall firewall show rule name="Windows Pack Control Center"` | 규칙 표시 |

## 업그레이드 설치

기존 버전이 설치된 상태에서 새 버전 설치 프로그램을 실행하면:
- 프로그램 파일이 자동으로 업데이트됩니다.
- 사용자 데이터(데이터베이스, 로그, 설정)는 보존됩니다.
- 설정 파일(appsettings.json)은 기존 파일이 있으면 덮어쓰지 않습니다.

## 문제 해결

### "포트 8088이 이미 사용 중입니다" 오류

```powershell
# 포트를 사용하는 프로세스 확인
netstat -ano | findstr :8088

# 해당 프로세스 종료 (PID 확인 후)
taskkill /PID <PID> /F
```

### 설치 실패 시

1. 관리자 권한으로 실행했는지 확인
2. 안티바이러스 소프트웨어가 차단하지 않는지 확인
3. 설치 로그 확인: `%TEMP%\Setup Log*.txt`
